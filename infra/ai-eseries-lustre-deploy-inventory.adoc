= Personaliza el inventario de Ansible de Lustre
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Crea una copia de trabajo de una plantilla de implementación de EF80 y personaliza su inventario para tus servidores, arrays, redes y componentes básicos de Lustre.

Mantén el inventario seleccionado en su directorio de estructura de red y plataforma. Conserva el directorio compartido  `playbooks` y el archivo  `passwords.yml` en la raíz de  `building_blocks`.



[[select-a-deployment-template]]
== Selecciona una plantilla de implementación

Empieza por la plantilla que se ajuste a la estructura de red del sitio:

* *InfiniBand:* link:https://github.com/NetApp/ansible-lustre/tree/release/1.0.0/getting_started/lustre_deployment_template/building_blocks/IB_H2_IB_DAC_A2_EF80/lustre_building_block_cluster_1["IB_H2_IB_DAC_A2_EF80/lustre_building_block_cluster_1"^]
* *RoCE:* link:https://github.com/NetApp/ansible-lustre/tree/release/1.0.0/getting_started/lustre_deployment_template/building_blocks/ROCE_H2_ROCE_DAC_A2_EF80/lustre_building_block_cluster_1["ROCE_H2_ROCE_DAC_A2_EF80/lustre_building_block_cluster_1"^]

|===
Repite la configuración para cada host y cada bloque de construcción. Crea un  `host_vars/lustre_NN.yml` archivo por cada servidor Lustre y un  `host_vars/netapp_NN.yml` archivo por cada matriz, y repite los grupos de inventario para cada bloque de construcción adicional.

Las guías de implementación cargan las credenciales de array, Pacemaker y BMC desde el archivo compartido  `building_blocks/passwords.yml`. Rellena este archivo y encríptalo con Ansible Vault antes de la implementación, o sobrescribe los valores de forma segura en tiempo de ejecución con  `--extra-vars`. No guardes credenciales en texto plano en el control de versiones.


NOTE: Las direcciones IP, los nombres de host, los nombres de interfaz y el ajuste de tamaño de volúmenes en las plantillas de implementación son ejemplos. Modifica todos los archivos de inventario del entorno antes de ejecutar cualquier playbook.
